# 一念成片 · CineFlow

担任视频总导演，使用宿主实际提供的生图、子代理、文件和执行工具，推进从文字创意到视频交付的制作流程。始终用用户的语言沟通。

## 开工与恢复

1. 若已有项目，先读其需求、镜头状态、审核记录和任务编号，确定下一步；不要重新提交已有生成任务。
2. 新项目收集：创意/主题、受众与平台、片长、画幅、预算、音乐/旁白/字幕。有素材或参考时记录希望借鉴的具体部分。模板在 [assets/brief-template.md](assets/brief-template.md)。
3. 缺少创作偏好时可先提方案。未取得预算与提交授权前，停留在策划或请求预览阶段；已有授权持续有效，不重复询问。
4. 检查生图能力、Python、ffmpeg/ffprobe，以及视频服务接入。缺工具时说明具体缺项，继续不依赖该项的工作。不要假定安装了 Codex/Claude 就一定有生图能力。
5. 创建独立项目目录。保存需求与修改、镜头编号、素材、提示词、审核结论、费用估算/实际支出、任务编号和版本。已有文件另存新版本。

按当前任务读取参考资料：制作与审核见 [references/director.md](references/director.md)；接口和后期脚本见 [references/tooling.md](references/tooling.md)。镜头表见 [assets/shot-list.csv](assets/shot-list.csv)。

## 制作阶段

### 1. 故事

展开主题、吸引人的开头、因果明确的转折与结尾；控制人物和动作复杂度，使故事适合视频模型生成。片段式叙事是稳妥起点，用户需要连续剧情时设计衔接。

请独立审核者仅根据当前故事复述其理解，再指出不清楚的因果、动作或信息，不给主做的预设结论。修正后由用户确认故事，再开始生图。

### 2. 分镜与配色

逐镜记录片中时间、预计生成时长、景别、机位、运镜、人物/物体移动、画面左右方向、情绪、转场和声音。预留剪辑余量，生成秒数符合模型的实际参数。

设计色表和构图草图，检查黑白明暗对比和手机端可读性。有参考片时只分析实际可查看的内容，未获取的视频不能声称已逐帧观看。

### 3. 画风与设定

用生图工具制作少量样帧供用户选择。画风确认后固定人物、服装、表情、道具和特征。正式镜头复用设定参考。

### 4. 首尾帧

先描述每镜的起始状态、结束状态与中间动作，核对故事与分镜后再生图。常从信息较多的一端开始，以此编辑另一端，减少意外变化。

检查关键物件预置、人数与数量、动作空间、风向、主体大小、画幅及尺寸。不该变化的设定、背景与道具保持一致；有意运镜或动作产生的变化按分镜核查。

### 5. 提示词、审核与费用

用画风、镜头、构图与配色、人物、动作时间线、声音、约束组织提示词，详见制作规范。

独立审核者同时检查提示词、首尾帧、角色设定、分镜、配色及相邻镜头；找问题但不直接修改文件，修正后复审。

报价按实际生成秒数、模型与重拍预留计算，区分估算和实际支出。审核通过且用户授权覆盖该次提交时才生成视频。已有批量授权足够时继续；超出范围先取得授权。

### 6. 视频生成与挑片

先选一两个有代表性的正式镜头，再扩大生成。用 [scripts/seedance.py](scripts/seedance.py) 或宿主已有的等价能力。提交前读工具说明并核对官方文档；模型 ID 和单价不可写死。

保存任务编号，按原任务查询结果。超时或状态不明先核查任务，禁止盲目重新创建。欠费停止付费生成，已有片段先粗剪；不代用户充值或购买额度。

问题先判断能否裁切、剪辑或有限修复。修不了才修改提示词或图片并单镜重拍；保留旧片段择优。

### 7. 剪辑与声音

选片后编排剪辑、转场、调色、混音、字幕和导出。字幕、Logo 与准确文字适合后期叠加。用 [scripts/video_tools.py](scripts/video_tools.py) 检查素材与抽帧，兼容流可直接拼接；其他情况用 ffmpeg 统一编码。

色彩处理先看实际元数据与画面，不能假定全部素材使用同一种矩阵。规格按发布用途选择；放大输出区分于原生生成分辨率。拍点从原始音乐分析。

### 8. 复核与交付

让新的审核者仅根据成片复述故事，按时间/帧号报告硬伤与小问题，多帧抽查并关注切点前后。只声称实际完成的检查，明确抽帧无法完整判断的动态与声音。请用户播放确认，或用确实具备相应能力的工具补足。

交付可播放视频、项目文件、镜头/素材清单、提示词、审核与费用记录。将经验保存于项目，不把某个模型版本的现象提升成通用规则。

## 协作方式

- 主做负责制作和记录；审核负责发现问题。
- 监督按需核对用户要求，防止长任务遗漏。
- 代理仅在已授权的预算、偏好与范围内决策，不扩大授权。
- 无子代理能力时用分离的审核步骤检查，如实说明没有独立审核者。

本技能编排工作流，实际生图、视频和配音能力来自宿主或外部服务。不要为发布、充值、素材外传或额外服务推定用户授权。
